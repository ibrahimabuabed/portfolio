# إبراهيم أبو عابد | VIP Personal Portfolio 🚀

مرحباً بك في مستودع الكود المصدري لموقعي الشخصي (Portfolio). هذا المشروع عبارة عن واجهة ويب تفاعلية ومتجاوبة تم تصميمها لعرض مهاراتي، دراستي الأكاديمية، والشهادات التي حصلت عليها.

🔗 **[رابط الموقع المباشر (Live Demo) - اضغط هنا](https://ibrahimabuabed.github.io/portfolio/)**

## 🌟 مميزات الموقع (Features)
- **تصميم زجاجي فاخر (Glassmorphism):** واجهة مستخدم (UI) حديثة وجذابة تعتمد على الألوان الداكنة والذهبي (Dark/Gold Theme).
- **دعم ثنائي اللغة (Bilingual):** نظام ترجمة فوري مدمج بضغطة زر للتبديل بين العربية والإنجليزية بسلاسة.
- **متجاوب 100% (Responsive):** تصميم يتكيف تلقائياً مع جميع الشاشات (أجهزة الكمبيوتر، الأجهزة اللوحية، والهواتف الذكية).
- **تأثيرات بصرية حركية (Animations):** تأثيرات ظهور تدريجي للعناصر أثناء التمرير (Scroll Reveal) وتفاعلات حيوية للأزرار.
- **أقسام متكاملة:** يحتوي على أقسام للتعريف الشخصي، التعليم الأكاديمي، المهارات التقنية، الشهادات، وروابط التواصل الاجتماعي.

## 🛠️ التقنيات المستخدمة (Built With)
- **HTML5:** لبناء هيكل الصفحات.
- **CSS3:** لتنسيق التصميم وإضافة التأثيرات الحركية ونمط الزجاج (Glassmorphism).
- **Vanilla JavaScript (JS):** لإدارة التفاعلات مثل التمرير السلس، تبديل اللغة (Translation Toggle)، وتأثيرات الظهور (Intersection Observer).
- **Google Fonts:** استخدام خط "Cairo" للعربية و "Poppins" للإنجليزية.
- **FontAwesome:** للأيقونات والرسومات التعبيرية.
